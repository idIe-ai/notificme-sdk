# @notificme/client (planned)

Client library to show the notific.me inbox and answer decisions inside your own web app, with your users signed in through your own SSO.

- Runs in the browser (also Capacitor/Ionic and React Native).
- Authenticates with a short-lived person token that your backend requests with `@notificme/sdk`.
- Inbox, real-time updates, open, dismiss and reply. No UI components: you render the cards (see [`protocol/`](../../protocol/)).

Not published yet.
